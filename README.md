# Barcode Wallet

Ad-free Android app to store and display Code 128 barcodes (gym, supermarket loyalty cards, etc.).

## How to get the APK

1. Go to the **Actions** tab in this repository.
2. Click the latest **Build APK** workflow run.
3. Under **Artifacts**, download **barcode-wallet-debug**.
4. Unzip the downloaded file — you'll find `app-debug.apk` inside.
5. Transfer the APK to your Android phone (email, Google Drive, USB, etc.).
6. On the phone: open the file, allow installation from unknown sources when prompted, install.

## Features

- Add barcodes by scanning with the camera or typing the value manually.
- Tap a barcode to display it full-screen at maximum brightness for easy scanning at checkout.
- Long-press a barcode in the list to delete it.
- All data stored on-device only — no internet permission.

## Requirements

- Android 8.0 (API 26) or higher.
